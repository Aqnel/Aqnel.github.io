Embedded Analog

RGB LED Colour Mixer

Built an interactive RGB LED colour mixer using an Arduino Uno, a common-cathode RGB LED, three rotart potentiometers, and three 220 Ω current-limiting resistors. Each potentiometer independently controls one colour channel via ADC input and PWM output, enabling the full colour spectrum to be created by rotating the potentiometers.

Arduino C PWM ADC Analog Circuits
